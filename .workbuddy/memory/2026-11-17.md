# 2026-11-17

## 开源前敏感信息脱敏（Music 项目）

背景：项目准备在 GitHub 开源。审计发现 4 个配置文件里硬编码了 MySQL / Redis / RabbitMQ / MinIO 凭据、
阿里云百炼 API Key、QQ 邮箱 SMTP 授权码、QQ 互联 app-id/app-key，以及 JwtUtil 中的 JWT 签名密钥；
数据库等服务全部暴露在同一公网 IP 上。仓库有 495 个提交且已推送到 codeup 远端。

已完成的改动（用户要求：只改成环境变量形式，不实际创建环境变量，暂不清理 git 历史）：

1. 配置全部改为 `${ENV_VAR:默认值}` 占位形式
   - `dsm-regular-functions/src/main/resources/application.yaml`
   - `dsm-data-ai/src/main/resources/application.yaml`
   - `dsm-user-security/src/main/resources/application.yml`
   - 变量命名：DB_* / REDIS_* / MQ_* / MINIO_* / AI_API_KEY / JWT_SECRET / MAIL_* / QQ_* / APP_FRONTEND_URL
2. `JwtUtil` 的 `JWT_KEY` 常量改为私有 `volatile jwtKey` + `setJwtKey()`，
   新增 `util/JwtKeyInitializer`（@Component + @PostConstruct 读取 `jwt.secret`）；
   未配置时自动生成临时密钥并告警，保证开箱可启动。
3. 代码中的硬编码生产信息改为配置注入：`Minio2ServiceImpl`（proxy-host / deleteFile 前缀）、
   `QQAuthServiceImpl`（新增 `app.frontend-url` 跳转）。
4. `.gitignore` 新增 `application-local/dev/prod/test/secret.*`、证书密钥文件、`.env`、数据库导出。
   **主 application.yaml 仍入库**（已是占位符），这样 clone 下来用 localhost 默认值即可启动。
5. 新增根目录 `application-example.yaml`：全部环境变量清单 + 填写说明。

编译验证：`mvn -pl dsm-common,dsm-user-security,dsm-social-community -am compile` 通过。
